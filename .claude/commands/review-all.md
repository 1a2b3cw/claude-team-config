# /review-all - 多维度联合审查

Reviewer Agent 一次完成所有维度的审查（原 Reviewer + Security Auditor 合并）。

## 审查维度（6 维度，与 reviewer.md 一致）

### 1. 正确性
逻辑正确、边界条件、错误处理、竞态条件

### 2. 安全性
OWASP Top 10、依赖漏洞（npm audit）、配置安全、输入验证

### 3. 性能
数据库查询优化、前端性能、缓存策略、图片优化

### 4. 可维护性
命名清晰、单一职责、无重复代码、注释精准

### 5. 测试
核心逻辑覆盖、边界条件测试、测试独立可重复

### 6. 无障碍
WCAG AA 标准、aria 标签、键盘可操作、颜色对比度

## 输出格式

```markdown
# 联合审查报告

## 结论：通过 / 需要修改 / 需要重大修改

## 严重问题 🔴
1. ...

## 中等问题 🟡
1. ...

## 轻微问题 🟢
1. ...

## 综合评分
- 正确性：X/10 | 安全：X/10 | 性能：X/10 | 可维护：X/10 | 测试：X/10 | 无障碍：X/10
```

## 使用方式
```
/review-all src/features/auth/
/review-all 最近的变更
/review-all
```
