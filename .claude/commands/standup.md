# /standup - 项目状态汇报

生成项目当前状态的简要汇报。

## 数据来源
- TaskList（任务进度）
- Git log（最近提交）
- 未解决的问题

## 输出格式

```markdown
# 项目状态汇报
日期：YYYY-MM-DD

## 已完成 ✅
- [任务] - [简要描述]

## 进行中 🔄
- [任务] - [当前状态]

## 阻塞项 🚫
- [问题] - [需要什么来解决]

## 下一步 📋
- [计划]

## 整体进度
- 总任务：X | 完成：X（X%）| 进行中：X | 阻塞：X
```

## 使用方式
```
/standup
```
